# Froggy-BLC (Book-Like CMS)

**Froggy-BLC** — это минималистичная отказоустойчивая CMS на PHP с файловой «базой данных», рассчитанная на сайты книжного типа: длинные статьи, структурированные как разделы и главы, плюс древовидные комментарии.  
Цель проекта — максимум прозрачности и контроля над данными без SQL и тяжёлых фреймворков.

> **Требования (кратко):** PHP **8.3** + браузер с поддержкой **HTML5** и **JavaScript**.

Домашняя страница проекта и подробнее о концепции:  
https://froggy-blc.com/?Froggy-BLC_(Book-Like_CMS)/1

## Для чего это

Froggy-BLC задумывалась как «Книжная Система Сайта». Лучше всего она подходит для:

- авторских сайтов с длинными текстами и сложной структурой;
- онлайн-книг и самоучителей, где важны разделы, главы и параграфы;
- личных «домашних» сайтов в духе старого веба;
- документации и заметок, которые нужно организовать в дерево, а не в плоскую ленту.

Ключевая особенность — **глубокое древовидное представление** как самих страниц (раздел → глава → параграф), так и комментариев.

## Основные возможности

- 📚 **Книжная структура сайта**
  - Материал организован как дерево: «книга → разделы → главы → параграфы».
  - Каждая страница содержит один `<article>` и обязательный `<h1>`.
  - Оглавление (ToC) строится автоматически на основе заголовков `<h2>–<h6>`.

- 🧵 **Древовидные комментарии**
  - Вложенные ответы (треды).
  - Постраничная навигация (по умолчанию ~8 веток комментариев на страницу).
  - Расчёт страниц комментов идёт от общего числа записей.

- 📁 **Файловая база данных вместо SQL**
  - Все данные живут в каталоге `DATABASE/` (HTML-файлы, служебные индексы, кэши).
  - Нет зависимости от MySQL/PostgreSQL — достаточно PHP и файловой системы.
  - Аккуратная работа с файлами: блокировки, временные файлы `*.new`, `*.lock`, защита от коллизий.

- ⚡ **Кэширование и производительность**
  - Кэш дерева оглавления (`DB-TOC-Cache.txt`).
  - Кэш меню (`MenuCache.txt`).
  - Кэш SEO-данных (`SEO-Cache.txt`).
  - Кэш обновляется только при админских действиях (добавление/редактирование/удаление материала).

- 🔍 **SEO и ссылки**
  - ЧПУ-адреса + стабильные SHA-1-пермалинк-идентификаторы.
  - Canonical-ссылки, `rel="bookmark"`, `rel="prev"` / `rel="next"`.
  - Генерация sitemap (текстовый и XML-варианты) для поисковых систем.

- 🛡️ **Безопасность**
  - Жёсткая фильтрация HTML через HTML Purifier и собственные фильтры.
  - Нормализация сущностей и «невидимых» юникод-символов.
  - Защищённые сессии: строгие настройки cookies (`SameSite=Strict`, `Secure`, `HttpOnly`, собственное имя сессии и т.п.).
  - Аккуратная обработка ошибок, чтобы не светить внутреннюю структуру.

- 🎨 **Чистый HTML5 + немного JS**
  - Разметка тянет на строгий HTML5, близкий к XHTML.
  - JS-счётчики для автоматической нумерации разделов.
  - Лёгкий JavaScript:
    - Лайтбокс для изображений.
    - Поиск по оглавлению/меню.
    - Обновление капчи.
    - Копирование адресов файлов.

## Идеология и вдохновение

При разработке Froggy-BLC автор вдохновлялся:

- ранними версиями **CMSimple** — хотелоcь получить систему с сильной семантикой и таксономией, где структура текста важнее «блёсток»;
- архитектурными монстрами вроде **MULTICS** и **X11** — отсюда стремление сделать что-то максимально самостоятельное, со своим видением и внутренней логикой;
- старым вебом, где сайт — это в первую очередь набор связанных текстов, а не набор виджетов.

Отсюда:

- упор на **логическую структуру документа** (заголовки, статьи, секции);
- **минимум магии** и залежей фреймворков;

## Требования

- PHP **8.3**
  - Минимальный набор модулей PHP:
    - `ctype`
    - `date`
    - `mbstring`
    - `iconv`
    - `json`
    - `hash`
    - `gd`
    - `intl`
    - `gmp`
    - `session`
    - `filter`
    - `pcre`
    - `SPL`
    - `random`
  - Модуль `gd` должен быть собран с поддержкой FreeType.
  - В большинстве обычных сборок PHP модули `ctype`, `date`, `session`, `filter`, `pcre`, `SPL`, `random`, `json` и `hash` уже входят в базовую установку, но в минимальных/кастомных сборках их всё равно нужно проверить.
- Веб-сервер (Apache, Nginx, Caddy и т.п.), умеющий запускать PHP 8.3.
- Браузер с поддержкой **HTML5** и **JavaScript** (любой современный браузер).

Базы данных **не нужны** — всё хранится в файлах.
